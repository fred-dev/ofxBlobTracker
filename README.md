# ofxBlobTracker

Classic blob tracker from CCV (by Patricio Gonzalez Vivo), wrapped as an openFrameworks addon: tracks blobs between frames and assigns them persistent IDs. See `example/`.

> **About this fork:** fork of [patriciogonzalezvivo/ofxBlobTracker](https://github.com/patriciogonzalezvivo/ofxBlobTracker) with a fix to build on OF 0.11 (2021).
